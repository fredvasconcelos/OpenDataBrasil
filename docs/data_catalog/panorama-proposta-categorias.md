# Proposta: dimensão principal de cada KPI (onda Total + %)

<!-- Gerado por `odb panorama propor`; não editar à mão. -->

Regra do mantenedor (ADR-0010): o KPI é o Total; as categorias da dimensão principal aparecem como % do Total; as demais dimensões ficam no Total.

A proposta vem dos descritores oficiais (`configs/catalog/descritores/`). A dimensão principal é a primeira classificação que não é um recorte comum (sexo, idade, cor ou raça, situação do domicílio, tamanho do município, localização, referência temporal). Os recortes comuns seguem como filtros. **Soma** diz se o IBGE permite somar as categorias (`CategoriasPodemSerSomadas`); sem soma, o % não é uma partição do Total e o portal mostra o valor de cada categoria. Para aprovar ou trocar uma linha, basta indicar a tabela e a classificação desejada.
