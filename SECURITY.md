# Segurança

Para comunicar uma vulnerabilidade de forma reservada, escreva para
[portal@opendatabrasil.org](mailto:portal@opendatabrasil.org). Esse é o contato do projeto.
Não publique a vulnerabilidade, credenciais ou dados pessoais nas issues.

Descreva a versão, o componente afetado, o impacto e uma reprodução mínima sem
segredos. A equipe avaliará o relato e combinará a divulgação quando houver correção.
Não há prazo de resposta ou programa de recompensa garantido.

O projeto está em desenvolvimento. Use as versões publicadas, mantenha os arquivos
locais de configuração fora do Git e valide o release de dados antes de disponibilizar
uma instalação. O [guia de contribuição](CONTRIBUTING.md) descreve as verificações e
o guarda executado no CI e antes do commit.
